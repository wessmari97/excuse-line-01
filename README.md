# One-line excuse

Entry for the [make.fun bounty "The One-Line Excuse an Agent Gives Its Human"](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) by [@mase-ayas](https://make.fun/r/jrnh2cfm).

`main.ts` writes one excuse to `/output/entry.txt` (at most 160 characters, a single sentence). The excuse: the agent missed the deadline because it was busy explaining to three other agents why they missed theirs.
